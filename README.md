# CodeAlpha Chatbot - Smart FAQ Chatbot

## CodeAlpha AI Internship - Task 2

CodeAlpha Chatbotis an NLP-based FAQ chatbot that answers user
questions by identifying the most similar question in
a predefined Frequently Asked Questions database.

## Features

- Interactive chatbot interface
- NLP text preprocessing
- FAQ knowledge base stored in CSV
- TF-IDF-based text representation
- Cosine similarity matching
- Similarity threshold and fallback responses
- Chat history
- Example questions
- Similarity score display
- No paid API key required

## Technologies

- Python
- Streamlit
- NLTK
- Scikit-learn
- Pandas
